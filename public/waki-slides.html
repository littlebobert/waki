Built with our hackathon sponsors

The right tool at every boundary.

Waki orchestrates the pipeline while each sponsor provides a focused, auditable capability.

QwenCloudEvidence → ProductSpec

Reads meeting text and screenshots—including the reference team image—and returns a strict, schema-validated ProductSpec. It never generates or executes application code.

QoderProductSpec → Frontend

Receives only the validated spec and seeded React/Vite project. With shell and web access disabled, it edits only the frontend; Waki owns and protects generated FastAPI files.

DaytonaBuild → Signed preview

Runs the isolated, time-bounded sandbox: installs Node and Python dependencies, builds React, compiles and smoke-tests FastAPI, starts the preview, and returns a signed expiring URL.
